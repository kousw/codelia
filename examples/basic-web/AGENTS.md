# examples/basic-web

React + Hono minimal web client driving `entry.agent.runStream()` over SSE (`POST /api/runs` + `GET /api/runs/:runId/events` with `Last-Event-ID`).

- **Storage & durable mode**: `DATABASE_URL` switches runs/sessions/settings from in-memory/`basic-web.settings.json` to Postgres (`postgres-run-manager.ts`, `worker_session_leases` sticky TTL via `CODELIA_SESSION_STICKY_TTL_SECONDS`). `CODELIA_RUN_ROLE=api|worker|all` splits API/SSE vs worker execution; `CODELIA_SANDBOX_TTL_SECONDS` cleans inactive per-session directories under `CODELIA_SANDBOX_ROOT`.
- **Client & SSE lifecycle**: `useChat.ts` + pure `chat-history.ts` restore history (omitting empty `assistant` turns) and auto-resubscribe to active `queued`/`running` runs on reload; stream EOF without `done`/`error` must resolve to `error` and release UI streaming state; `POST /api/sessions` persists empty `new chat` sessions immediately so listing/restore works; `SessionManager.delete` deletes state files physically; `routes/chat.ts` aborts on `c.req.raw.signal`.
- **Auth & settings**: `routes/settings.ts` invalidates `AgentPool.invalidateAll()` on update and returns masked keys only. `CODELIA_OPENAI_OAUTH_PUBLIC_BASE_URL` enables public callback + `oauth_state` DB; unset uses loopback (`CODELIA_OPENAI_OAUTH_PORT`); empty `CODELIA_OPENAI_OAUTH_CLIENT_ID` falls back to default client ID; OAuth runs attach `ChatGPT-Account-Id` when `account_id` exists; multi-instance Compose (`docker-compose.multi.yml`) uses Traefik (`traefik/dynamic.yml`). `Dockerfile` needs `build-essential` for `better-sqlite3`.
- **Commands**: `cd examples/basic-web && bun run dev` (`dev:durable` / `dev:api` / `dev:worker`), `bun run lint|check|fmt|typecheck`, `bun run --filter '@codelia/basic-web' build`, `docker compose up --build`.
