# Runtime RPC Handlers (`packages/runtime/src/rpc/`)

Spec: `dev-docs/specs/ui-protocol.md` & `dev-docs/specs/protocol-codegen.md`.

## Envelope, Validation & Concurrency

- Validate envelopes and object-shaped params against `@codelia/protocol` `protocolMethods` via `parseRequestParams` *after* handler gates (`INVALID_PARAMS` returns bounded `data.issues` without echoing input values; pass original raw params to local unknown-key checks on stripping schemas; preserve v0 reasoning normalization before `model.set` parse). Outgoing payloads emit unchanged and assert only when `CODELIA_TEST_PROTOCOL_ASSERT=1` (set by root test preload). `parseUiResult` contract violations fail closed as declined dialogs.
- Each request emits at most one response (send a generic internal error only if no response has been sent yet). `run.start` client tools and goal tools fail admission (and release any goal reservation) unless approval registration succeeds.
- Failed pre-response `run.start` setup must release admitted runs without auto-replaying uncertain requests. Request receipts (`tool.call` vs dispatcher shell/task starts) prevent in-connection replay.
- `RuntimeState.withAdmissionLock()` serializes idle-only management writes (`config.set`, `permissions.remove`, API-key `auth.login`, `auth.storage.resolve_conflict`, `sandbox.set`, `auto_review.configure` writes) with `run.start` admission through `beginRun`.

## Handler Invariants

- **Auth (`auth.ts`, `auth-management.ts`)**: `auth.status` reads credential slots in place (including legacy) without taking the auth lock or migrating, projecting only method/expiry plus `storage` and `warnings` (`inline_mcp_config_secrets`, `mcp_reauth_required`, `storage_conflict`, Keychain errors). OAuth/device-code login claims `settled` before saving credentials so concurrent cancel returns `cancelled: false`; reload-then-merge updates invalidate cached agents via `RuntimeState.requestAgentInvalidation()`. `auth.logout { provider }` requires `supports_scoped_logout` and `clearProviderAuth` (never fall back to `clearAuth`; invalidate affected direct/image tools; reset session only for matching chat provider). `auth.storage.resolve_conflict` requires confirmation + idle lock and revokes local auto-review auth.
- **Model (`model.ts`)**: `model.set` and session reset validate speed/reasoning/model/auth before mutating live override, `sessionMeta`, or cached agent; normalize inherited boolean `fast` to `false` (never auto-upgrade/reject) and reject explicit `fast` when targeting Google/DeepSeek; validate inherited reasoning for named Responses endpoints.
- **Config, Permissions & Sandbox (`config.ts`, `permissions.ts`, `sandbox.ts`)**: `config.get`/`config.set` serve only allowlisted "last wins" scalar keys in `../config-keys.ts` (never command-running or credential/endpoint-redirecting keys); resolve project config from agent workspace root. `permissions.list` resolves mode without triggering startup selection; `permissions.remove` matches structurally and never edits `projects.json`. `sandbox.set` is workspace-scoped, idle-only, and respects CLI/env/SDK overrides; mirror `initialize.local_host` Auto approve startup status into `initialize.tui` for older clients.
- **Metrics, Errors, Steer & Goals**:
  - `run-metrics.ts`: derive TPS only from finite non-negative output usage and positive monotonic generation interval (reject <250ms intervals and hidden reasoning without `reasoning_item`/`thought_step` activity); `null` leaves prior TUI rate intact and call starts never emit resets; `normalizeRunFailure().statusError` shares stack-free `RunErrorInfo`.
  - `run.steer`: serialized separately from run admission, rechecks active run after image prep, keeps polled steers unconfirmed until `steer_applied` (echoing unconsumed IDs in terminal `unconsumed_steer_ids`, preserving run-scoped client ID index for retries).
  - `goals.ts`: `goal.pause` latches before queue serialization; emit `goal.ready` only after checkpoint succeeds and `finishRun` releases the run.
  - Attachments & tasks: treat client attachment IDs as unresolved until integrity + session ownership pass; claim unbound draft uploads only during fresh session admission (after verifying reader permission/vision) and discard them on `session.open`, session switches, or resets; pin accepted Steers until application/fallback; `task.progress` coalesces to 250ms per task (state changes immediate, unref'd trailing timer).
