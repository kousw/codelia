# Runtime Image Generation (`packages/runtime/src/image-generation/`)

Spec: `dev-docs/specs/image-generation.md` (§1.1–1.5).

## Route, Auth & Reference Invariants

- Never fall back across mode, provider, model, endpoint, account, auth, or billing; metadata discovery is not account verification, and paid calls never retry automatically (including timeouts).
- `route.ts`: builtin follows active OpenAI chat auth (Codex OAuth uses `codex.ts` + `AuthResolver` token/account check at fixed Codex origin; API-key uses public Image API); custom OpenAI/OpenRouter/Google use explicit `api_key_env` exclusively (missing/empty fails with `missing_api_key`), or when `api_key_env` is omitted fall back from stored API key to the standard provider env var (never OAuth or chat-auth switching). Config accepts env var names only, never literal keys, headers, or arbitrary URLs.
- `adapter.ts` / `google.ts`: validate endpoint options and pin a single OpenRouter endpoint before request (`fallback: false`); Google uses Interactions API with `store=false`, rejects explicit PNG output locally (accepting default or `"jpeg"`), and preserves returned PNG/JPEG originals. Reject unsupported formats rather than converting silently.
- `references.ts` / `source-reader.ts` / `source-proxy.ts`: validate ordered `images` (or exclusive `reference_artifact_ids`) via `image-size` headers (32 MiB/file, 128 MiB combined, 12288px/20 MP, count limits: 16 OpenAI/OpenRouter, 5 Codex, 14 Google; reject GIF/errors before paid calls without dropping references). For local files, when resource protection is enabled reads go through `SandboxContext.withSelectedFile(..., "read")` (ordinary user-readable paths allowed; `protected_paths` and Codelia credentials rejected); otherwise `readonly`/`workspace-write` confine resolved paths to the workspace root while `full-access` permits paths outside it. Reference URL fetching uses `source-reader.ts` (never authenticated generation transport), preserves TLS verification, never mutates the global HTTP agent, and omits proxy URLs/credentials from errors (`HTTP_PROXY`/`HTTPS_PROXY`/`ALL_PROXY`/`NO_PROXY`; lowercase wins; scheme-specific overrides `ALL_PROXY`; direct fallback prohibited; Bun 1.4.4+ / Node 22.21+ / 24.5+). Direct and `NO_PROXY`-bypassed connections enforce socket-level public-IP DNS checks locally; for proxied hostnames, the configured trusted proxy owns DNS resolution and final destination enforcement while Codelia checks URL syntax, private IP literals, redirects, timeouts, and byte limits.
- **Storage & history (`attachments.ts`, `local-store.ts`, `tools.ts`, `export.ts`)**: `prepareRunImages` imports inline attachments at run admission without remote fetches or automatic legacy rewrites; save validated immutable originals before reporting success; `store.modelReference` pins admission-time JPEG views on new generated opaque refs only (never mutating legacy history or rotating old images to text); keep generation/export permission gates inside tool execution (`executeRaw` returns `{ type: "parts", parts }`); compose local stores/auth for `tui-local` only.
